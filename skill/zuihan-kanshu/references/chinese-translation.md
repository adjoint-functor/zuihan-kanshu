# 中文翻译模组

仅当任务把一份明确来源翻译成中文，或审核既有中译稿时加载本模组。直接用中文新写文稿不因此加载翻译模组。翻译只改变语言，不自动启用研究、文风整理或成品流程；普通文稿同时遵守 `working-draft.md`。

活动研究项目只翻译用户明确指定版本的数学主稿，并生成独立衍生稿。翻译选择不得反写研究主稿，也不得被当作数学进展。

## 先划定输入与保护区

1. 固定源文件、源版本和实际翻译范围；以该来源的读者正文为准，不把旧工程档案、角色输出、任务清单或历史日志翻译成读者内容。
2. 先识别正文、公式、代码、逐字保留片段、引文和参考文献区域，再处理语言；不得把全文件当成无结构字符串替换。
3. 逐字保留的原文引文、参考文献列表及 BibTeX/CSL 数据是只读保护区。作者姓名、题名、期刊或书名、出版社及其他书目字段保持来源语言与来源文字；引用键、DOI、URL 和文件名逐字保留。可以统一用户要求的样式、标点、顺序和数学排版，也可以读取书目字段来消歧正文身份，但不得把正文译名回写到书目字段。

## 按需加载两份参考表

- 源文含英文数学术语，或任务要求审核英文术语的既有中译时，读取 `translation-glossary-en-zh.md`。
- 正文含具体日本人名、地名、机构名或日语人名来源数学术语时，读取 `japanese-names-places-zh.md`。
- 没有相应输入时不加载无关表；两表都不是普通词典，也不得整表复制到产物中。

英文术语表只有在下列条件全部满足时才是免去本轮专门联网的快速通道：

1. 源词与表项精确匹配；
2. 数学义项、对象类型和语法功能与表项范围一致；
3. 用户明确指示、用户已明确采用的同义项项目译名及本次适用的源文双语约定没有更高优先级的不同选择；
4. 没有尚未消解的身份或语义冲突。

命中后直接采用表中形式，不为每次出现重复查网，也不在控制稿重复抄录旧证据。新词、义项变化、对象不明、项目冲突或表外多义词必须进入查证流程；不得由词形、前后缀或相邻表项机械拼出译名。多个来源词可能重叠时先匹配最长的完整术语；禁止子串替换和全局替换。

## 术语决策顺序

先由数学对象和源文定义判定义项；译名的优先级不能改变数学内容。对需要决策的中文形式依次检查：

1. 用户明确的译法指示，包括本轮选择及仍适用的后续用法指示；
2. 用户已明确采用、且同一义项适用的项目译名；
3. 源文明确给出的双语约定，按本次翻译目的处理；
4. 两份技能参考表中的精确命中；
5. [术语在线](https://www.termonline.cn/) 中的同一数学义项；
6. [国家教育研究院乐词网](https://terms.naer.edu.tw/) 中的数学及区域用法；
7. 权威中文专著、教材和专业期刊的实际用法。

用户语义上明确表示“此处译为”或“以后采用”等，即可确定适用范围，无需固定口令。随口讨论、临时简称、提问中的用词、模型反复使用的译名或助手自写术语表，均不自动构成已获采用的项目约定；没有明确采用的对话惯用法不能覆盖技能表的精确义项。已有且无冲突的译法无需逐词追索批准凭据，旧稿仍可阅读，也不因默认表更新而批量改写历史材料。

普通英文讨论或源文对数学对象的定义，不等于给出了中文译名约定。源文确有双语约定时，若任务旨在忠实复现该约定，应保留；若任务要求按指定目标译名转换，则遵从用户指示，必要时说明对应关系。不得把译名冲突当作改写定义的理由。

必须比较数学义项而不是拼写。区域性用法只作为相应区域证据；搜索摘要、普通词典、机器翻译和词素类推只能提供候选，不能单独决定技术译名。证据薄弱、互相冲突或中文候选降低精度时保留来源词，并写明本文件中的适用范围。

表项与用户或项目冲突时服从较高优先级选择，只在本译文中记录覆盖范围；不得在翻译任务中静默改写技能表。发现技能表本身疑似错误时暂停该表项的自动采用并报告，后续通过单独的技能维护处理。

## 人名、地名和日语例外

一般人名保留来源文字，只翻译合适的数学通名。日本实体按 `japanese-names-places-zh.md` 的封闭规则处理：先解析完整身份或精确命中固定人名术语，再采用表中中文正文形式；裸姓、同名人物和未列变体不得猜测。

多人术语只转换表内已解析的日本人名部分，其他人名保持原文。正文首次出现是否并列罗马字只由消歧或教学需要决定，不反复混写。无论正文如何处理，参考文献保护区始终保持来源形式。

## 保持数学内容

1. 保留全部假设、量词、逻辑依赖、限定语、公式、符号、例子、反例、条件性结论、障碍和开放问题。
2. 可以调整句法以形成自然中文，但不得借翻译之名简化、扩充、重证、纠错或改变数学实质。
3. 保留编号、标签、交叉引用、引用关系和书目标识。
4. 沿用项目记号。确需转换记号时，先写明一次对应关系，再检查全文所有出现位置。
5. 表示论中的归一化因子、指数、左右作用和测度约定只忠实翻译源文已经给出的内容；张量积、对偶和余商的拓扑、闭包及完备化也依来源保留。不得因术语表的义项说明自行补写假设、补取光滑部分，或断言求和、积分、留数等操作可交换。

## 读者术语表与内部记录

- 正文统一使用已选形式，避免反复写成“中文（English）”或把翻译争论插入段落。
- 在读者正文最后一个适用位置设置“术语与翻译表”，列出本文件实际采用的新词、非显然词和为消歧而保留的来源词；至少写源词、采用形式和必要的义项限定。该表属于读者内容并保留在 PDF 中。
- 技能表的精确命中无需逐条重记证据。只有本轮新查证、冲突覆盖、保留源词或未决歧义，才在控制稿的“来源与构建”中记录证据与范围；在“编辑与检查记录”中记录翻译处理、实际保真审核、未决项和相对基版的变化。保留仍适用的既有记录，不为本次翻译重写历史。

## 保真审核

交付前完成以下检查：

1. 对照源版本检查标题、段落覆盖、公式、标签、交叉引用、引文和参考文献是否齐全；
2. 检查假设、否定、条件、量词和逻辑连接词是否遗漏或改变强弱；
3. 逐项确认保留的外文术语是有意选择，而不是漏译；
4. 确认每个本轮新采用或发生冲突的术语进入读者术语表，并有必要的内部记录；
5. 对参考文献保护区作字段级对照，确认正文中的中文人名和术语没有传播进去；
6. 报告仍未消解的歧义，不得静默选择数学上更强或更弱的读法。
