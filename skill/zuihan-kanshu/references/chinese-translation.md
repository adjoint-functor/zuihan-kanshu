# 中文写作与翻译模组

凡任务有实际预期的中文输出，按 `SKILL.md` 的语言及阶段判断在组织该部分前加载并使用本模组，涵盖对话、帮助、规划、数学问答、研究简报及文稿；混合输出只处理中文部分。正式研究内部的推导、检索和核验阶段不加载本模组，每轮收束真正撰写中文报告时才使用；本轮已加载时不据此干预内部研究过程或判断。指导用于适用输出的术语、自然表达和数学内容保护，不虚构外文来源或逐句对照。

中文数学文稿新写、修订和一次成稿仍须前置使用本模组，并按 `working-draft.md` 完成最终中文审查，再做文风审查。普通对话不因使用本模组而要求稿件控制、稿件术语附录、全稿终审、独立轮次或 PDF；共享中文参考按下节独立处理。单独翻译不自动启动研究或完整成品制作。

从活动研究项目翻译文稿时，只翻译用户明确指定版本的数学主稿，生成独立衍生稿；翻译选择不反写研究主稿，也不记为数学进展。正常中文研究讨论、简报和问答可在实际授权内继续数学工作。

## 先划定输入与保护区

1. 翻译既有来源时固定真实源文件、源版本或实际原文片段及范围，以来源内容为准，不把无关工程档案、角色输出、任务清单或历史日志翻译成读者内容。原生中文输出按实际问题、材料和数学定义组织，不假设存在外文底稿。
2. 处理既有材料时先识别正文、公式、代码、逐字保留片段、引文和参考文献区域，再处理语言；不得把全文件当成无结构字符串替换。
3. 逐字保留的原文引文、参考文献列表及 BibTeX/CSL 数据是只读保护区。作者姓名、题名、期刊或书名、出版社及其他书目字段保持来源语言与来源文字；引用键、DOI、URL 和文件名逐字保留。可以统一用户要求的样式、标点、顺序和数学排版，也可以读取书目字段来消歧正文身份，但不得把正文译名回写到书目字段。

## 按需加载两份参考表

本模组每次适用启动时，按 `shared-chinese-reference.md` 解析并读取全项目共享的中文参考；同一轮已读取且仍适用可复用，拟写入前读取最新版本。随后按当前术语需要加载两份内置表，不因已有共享缓存跳过内置精确义项的优先级。

- 实际材料含英文数学术语，或需要确定、审核其中文形式时，读取 `translation-glossary-en-zh.md`；原生中文稿也按真实术语来源与定义使用，不为凑对照杜撰源词。
- 正文含具体日本人名、地名、机构名或日语人名来源数学术语时，读取 `japanese-names-places-zh.md`。
- 没有相应输入时不加载无关表；两表都不是普通词典，也不得整表复制到产物中。

英文术语表只有在下列条件全部满足时才是免去本轮专门联网的快速通道：

1. 源词与表项精确匹配；
2. 数学义项、对象类型和语法功能与表项范围一致；
3. 更高优先级的当前要求、仍适用的明确用户／项目规则及任务适用的源文双语约定没有不同选择；
4. 没有尚未消解的身份或语义冲突。

命中后直接采用表中形式，不为每次出现重复查网，也不在控制稿重复抄录旧证据。新词、义项变化、对象不明、项目冲突或表外多义词必须进入查证流程；不得由词形、前后缀或相邻表项机械拼出译名。多个来源词可能重叠时先匹配最长的完整术语；禁止子串替换和全局替换。

## 术语决策顺序

先由数学对象和实际定义判定义项；翻译稿对照真实源文，原生中文稿核对术语来源与数学定义。译名的优先级不能改变数学内容。对需要决策的中文形式依次检查：

1. 用户当前明确的译法、保留形式或其他语言要求；
2. 仍适用的明确用户、项目或共享个性化规则，仅在已授权的对象、义项和作用域内；
3. 源文明确给出的双语约定，按本次翻译目的处理；
4. 两份技能参考表中的精确命中；
5. 共享参考中相同义项、证据适用且无冲突的已查证补充；它不覆盖内置精确表项；
6. 新查证：依次核对[术语在线](https://www.termonline.cn/)、[国家教育研究院乐词网](https://terms.naer.edu.tw/) 的同一数学义项及区域用法，再查权威中文专著、教材和专业期刊的实际用法。

用户语义上明确表示“此处译为”或“以后采用”等，即可确定适用范围，无需固定口令。随口讨论、临时简称、提问中的用词、模型反复使用的译名或助手自写术语表，均不自动构成已获采用的项目约定；没有明确采用的对话惯用法不能覆盖技能表的精确义项。已有且无冲突的译法无需逐词追索批准凭据，旧稿仍可阅读，也不因默认表更新而批量改写历史材料。

普通英文讨论或源文对数学对象的定义，不等于给出了中文译名约定。源文确有双语约定时，若任务旨在忠实复现该约定，应保留；若任务要求按指定目标译名转换，则遵从用户指示，必要时说明对应关系。不得把译名冲突当作改写定义的理由。

必须比较数学义项而不是拼写。区域性用法只作为相应区域证据；搜索摘要、普通词典、机器翻译和词素类推只能提供候选，不能单独决定技术译名。证据薄弱、互相冲突或中文候选降低精度时保留来源词，并写明本文件中的适用范围。

表项与明确用户规则冲突时服从较高优先级选择，记录实际覆盖范围；共享文件只按 `shared-chinese-reference.md` 接纳已落实条目，不把普通缓存、口头用词或助手习惯提升为例外，也不静默改写技能表。发现技能表本身疑似错误时暂停该表项的自动采用并报告，后续通过单独的技能维护处理。

## 人名、地名和日语例外

一般人名保留来源文字，只翻译合适的数学通名。日本实体按 `japanese-names-places-zh.md` 的封闭规则处理：先解析完整身份或精确命中固定人名术语，再采用表中中文正文形式；裸姓、同名人物和未列变体不得猜测。

多人术语只转换表内已解析的日本人名部分，其他人名保持原文。正文首次出现是否并列罗马字只由消歧或教学需要决定，不反复混写。无论正文如何处理，参考文献保护区始终保持来源形式。

## 保持数学内容

以下来源继承要求用于翻译及对既有材料的语言编辑。正常问答和研究可在已授权数学范围内推导、证明和纠错，同时准确表达必要条件、证据及结论状态；不能把语言保护误作禁止数学工作的规则。

1. 保留全部假设、量词、逻辑依赖、限定语、公式、符号、例子、反例、条件性结论、障碍和开放问题。
2. 形成自然的中文句法、衔接和数学表达；原生中文稿避免翻译腔，翻译稿不得借语言处理之名简化、扩充、重证、纠错或改变数学实质。需要数学修订时回到已授权的数学工作范围处理。
3. 保留编号、标签、交叉引用、引用关系和书目标识。
4. 沿用项目记号。确需转换记号时，先写明一次对应关系，再检查全文所有出现位置。
5. 表示论中的归一化因子、指数、左右作用和测度约定只忠实翻译源文已经给出的内容；张量积、对偶和余商的拓扑、闭包及完备化也依来源保留。不得因术语表的义项说明自行补写假设、补取光滑部分，或断言求和、积分、留数等操作可交换。

## 读者术语表与内部记录

- 对话只在帮助理解时简明解释必要术语或对应关系，不为加载本模组另建稿件术语附录和控制文件；共享参考的读取、必要初始化与合格增量独立进行。
- 正文统一使用已选形式，避免反复写成“中文（English）”或把翻译争论插入段落。
- 文稿确有需说明的新词、非显然词或为消歧保留的来源词时，在读者正文最后一个适用位置设置“术语与翻译表”；写真实源词、采用形式和必要义项限定，属于读者内容并保留在 PDF 中。原生中文稿仅在有阅读需要时列术语说明；没有相应词项不空设表，也不虚构外文对照。
- 技能表的精确命中无需逐条重记证据。文稿中只有本轮新查证、冲突覆盖、保留源词或未决歧义，才在控制稿的“来源与构建”中记录证据与范围；在“编辑与检查记录”中记录翻译处理、实际保真审核、未决项和相对基版的变化。保留仍适用的既有记录，不为本次翻译重写历史。普通对话引用实际采用的来源，说明影响回答的未决歧义即可。

## 中文审查与保真审核

对话在回答前检查适用的术语、表达和数学条件，不另开审查轮。实际文稿在实质写作完成后按 `working-draft.md` 安排最终中文审查，前置使用本模组不能替代后期审读。原生中文稿顺序检查交付范围内的术语义项、自然表达、指代衔接、数学定义与内容保护；核对真实来源及原文书目，不制造外文底稿或虚假的逐句保真记录。仅修局部时覆盖相应范围及必要上下文。

有真实外文底稿的翻译或中译审查，另完成以下保真检查：

1. 对照源版本检查标题、段落覆盖、公式、标签、交叉引用、引文和参考文献是否齐全；
2. 检查假设、否定、条件、量词和逻辑连接词是否遗漏或改变强弱；
3. 逐项确认保留的外文术语是有意选择，而不是漏译；
4. 确认文稿中需要说明的新词或冲突进入适用的读者术语表，并有必要记录；对话在需要处简明消歧；
5. 对参考文献保护区作字段级对照，确认正文中的中文人名和术语没有传播进去；
6. 报告仍未消解的歧义，不得静默选择数学上更强或更弱的读法。
