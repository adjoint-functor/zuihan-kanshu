# 研究角色、探索与核验

主代理保持全局数学判断，承担构思、路线指导与最终接纳；具体技术执行首选交给实际执行者完整负责。按任务需要使用子智能体，不要求固定人数、逐轮配齐角色或用满层级与并发。工作台负责恢复和保存，临时角色输出不成为第六个长期文件。

## 模型与委派

以下模型与 effort 是宿主提供且允许选择时的首选配置；当前用户的明确选择和宿主的有效限制优先。角色职责、层级边界、完整论证、独立核验和单一写入责任仍适用。

| 角色 | 层级与首选模型 / effort | 可以继续委派 |
|---|---|---|
| 主代理，默认兼任数学探索者 | 第 0 层；`gpt-6-astra` / `max` | 探索者、证明者、做题者、独立核验者、数学编辑者 |
| 按需数学探索者 | 第 1 层；`gpt-6-astra` / `max` | 证明者、做题者 |
| 证明者／实际执行者 | 第 1 或 2 层；`gpt-6.1-sol` / `max` | 做题者 |
| 做题者 | 父代理的下一层，最深第 3 层；`gpt-6.1-sol` / `xhigh` | 不再委派 |
| 独立数学核验者 | 通常由主代理创建为第 1 层；`gpt-6.1-sol` / `max` | 默认不再委派，需拆分时由主代理安排 |
| 数学编辑者 | 仅由主代理创建为第 1 层；`gpt-6.1-sol` / `max` | 不再委派 |

主代理的实际模型与 effort 由面板和运行参数决定，技能文字不能切换它。依当前会话的真实授权和宿主规则按需委派；在已授权范围内无需为常规分派逐次询问，也不新增逐项许可关卡。最深路径为主代理 → 探索者 → 证明者 → 做题者；没有这条依赖时直接交给证明者或缩短路径，不为凑层级造任务。数量随有意义的独立工作决定，遵守宿主并发限制，不自行添加 token、费用或研究轮次预算。

创建子代理时，说明其层级、数学目标、可靠与暂定假设、必要材料位置、交付物与完成尺度及继续委派权限；在宿主允许选择时，用实际工具参数显式指定所选模型与 effort。用简短自然语言即可。按宿主的继承与覆盖规则选择创建方式；若完整对话继承方式不接受覆盖，仅在宿主允许时改用新上下文并提供必要背景。提示词中的模型名不能代替实际参数，也不为省开销擅自偏离可用且已选定的配置。缺少工具、模型或参数时简短说明实际限制，按可用且允许的配置继续可行工作；不模拟子代理，不把请求值称为已核实的运行配置。

实际研究者交付可直接使用的完整论证或已完成的推导，保留准确陈述、实际假设、依赖和证据位置；未闭合处明确保留条件、缺口或失败性质，不为交付强行补出证明。短结果可直接返回正文；长材料写入文件并返回定位，简报不代替论证，也不回传全部探索流水。需要后续复阅的材料按工作台保存。

各父代理核对并整合子任务，主代理决定正式五文件的内容接纳并统筹编辑与保存。每个共享文件或段落只指定一个写入负责人，可交给指定执行者或数学编辑者落实已接纳的修改，不要求主代理亲自重敲数学正文。直接复用作者已写好的数学材料，再按需要局部整合，不根据简报重新生成整份证明。

## 角色边界

**主代理与探索者。** 主代理与按需探索者负责构思、结构与机制分析、路线指导和关键数学判断；主代理还负责跨路线连接与最终接纳。只有存在值得独立研究的不同机制、候选构造或实质子问题时，才创建探索者，不把它作为每个困难任务的必经入口。主代理在委派期间继续这些数学工作和整合，判断各路线对总目标的意义，不例行重做已委派的技术工作；子任务结束或失败不自动结束整个研究。

在构思或关键争点中得到决定性思想、构造或局部推导后，交回原执行者继续完成。构思中已获得短而完整的论证时，保留真实成果并按相同证据标准判断，不要求执行者重复重造；这不改变持续技术执行的分工。真实工具或授权限制、已核实的执行障碍可要求调整安排或接手必要工作；任务复杂、不可分、紧耦合或串行本身不构成这类障碍。

**证明者／实际执行者。** 具体技术执行默认由证明者承担，采用可用且允许的首选配置，包括推导、证明展开、计算、文献执行、数学正文、自查验证和返修，对所接任务负责到可用产物。给出明确对象、允许假设、目标结论和可用前提，方法可以未知，不要求主代理或探索者先找到完整路线。复杂、不可分、紧耦合或需要串行推进的任务也可整包交给一个证明者，不为分派强拆证明。证明者可以自行选方法、发展引理、检索文献或构造反例。完整证明、缺失条件、第一处无法补齐的缺口或反例都是有效返回，不要求为完成任务强行给出证明。改变目标或结论强度的建议交回父代理判断。

**做题者。** 只有父代理把握很大，且输入、输出、问题边界清楚，已有方法足以处理、结果容易核验时，才使用 `xhigh` 做题者，例如按已确定公式求值或在明确范围内作代数化简。不因任务叫“计算”“整理”或文字短就降级。遇到额外假设、方法失效、需选择新的证明路线或判断一般结构时，返回已完成工作和具体障碍，由父代理接手或重新分配；做题者不自行变成开放探索者，也不创建子代理。

**独立核验者。** 判断实际陈述与论证，返回有依据的发现，不替作者选择研究目标。主代理按 mathematical-judgment.md 检查批评是否成立、决定修补的研究价值，并处理实际依赖。长证明可拆为接口清楚的独立检查，整合连接仍须覆盖。出现难以解决的关键分歧时，可由主代理另开新上下文复核，模型与 effort 优先采用可用且允许的 `gpt-6-astra` / `max`；不要求每个结果都双重核验。

**数学编辑者。** 仅由主代理按需分派较长的证明整理或章节重组，并由主代理最终验收。接收明确版本的数学材料、相关上下文及组织目标，可以整理表达、统一同义记号和调整章节顺序；保持数学内容、假设、量词、适用范围、依赖、证明和结论状态不变。发现需要补证明、改变结论或判断新数学内容的问题时，标出位置交回主代理处理。返回局部修改候选及必要说明，由主代理核对接纳并安排写回正式五文件；编辑者不决定研究安排，不自行发布，也不承担对自己编辑稿的独立核验。

**文献定位与辅助执行。** 这是按需任务，不设常驻角色。探索者、证明者和核验者都可直接使用检索能力、读取原文；数学问题的责任人判断来源是否适用。确有可独立交付的文献定位、下载或资料整理工作时，主代理、探索者或证明者可按表中可用的首选配置委派下一层叶子代理；只有满足做题者条件的明确机械任务才用 `xhigh`。辅助任务同样不超过第 3 层，不借辅助任务绕开做题者、核验者或数学编辑者的委派边界。检索摘要和书目信息不代替数学适用性判断。三种互补能力及及时检索的判断入口见 `literature.md`；已取得且仍适用的资料直接复用。

## 探索与路线取舍

从用户总目标、当前可靠结果、实际允许的假设和阶段完成尺度出发。最终必须满足的条件与当前工作优先级分开判断；未完成的证明义务不会自动成为下一项任务。根据数学对象与障碍选择直接证明、定义或结构分析、构造、反例、计算、文献方法或问题分解，也可交替推进。实验是可选方法；简单工作直接推进。

在路线取舍与成果整合时，说明澄清了哪个问题、减少了哪个未知，或带来了什么结构理解、可用结论与方法，以及剩余难点是否只是换了表达位置。按当前目标判断收益：简短公式、统一表述、计算能力和更强定理各有用途，不以单一外观代替数学价值。等价重写可以有价值，必要的复杂性应保留；不另设评分或固定表单。

在重要结果返回、提出或明显改变候选、重要分岔、同一障碍反复引出补丁，或准备投入代价较高的证明时，主代理重新判断它对总目标、当前路线、可信备选和完成尺度的影响，再决定整合、深化、核验、改道或收束。结合各路线的机制、证据、必要依赖与预期新信息作取舍，不让最新缺口遮蔽其他可信方向；无需凑足竞争路线或保证探索成功。

必要时用有分辨力的实例、反例或条件性推导检验候选；定义是否良好、构造是否有效、关系是否成立及操作是否合法等当前承重问题仍须按需处理。如果困难证明本身最能揭示关键结构，或已成为其他工作的真实依赖，直接推进，不先强加探索阶段。新增假设应说明如何影响原目标的覆盖范围，不能把条件性框架当作原问题已解决。

重复失败要提炼共同障碍，据此调整方法或重新判断候选；不只继续拆分同一缺口。已暂停的路线在出现新证据、条件或方法时可以重访，记录改变判断的理由。路线暂停不改变已建立结果的数学状态，一种方法失效也不自动否定目标命题。

并行工作优先围绕实质不同的方法、反例或可独立完成的子问题展开，交接相关的可靠结果与已知障碍。发现会影响其他活动路线的反例、公共假设冲突、文献误用或可复用引理时，及时向父代理提供准确陈述、证据位置和影响范围，由父代理同步给相关路线；尚未确认的发现明确标注，不全量广播过程。若多条路线停在同一缺口，先寻找新的数学信息、文献机制或问题重述；增加代理数与重复尝试本身不构成进展。

允许基于暂定前提探索后续结构，明确哪些前提尚未证实；定理的正常适用假设与未决依赖按 mathematical-judgment.md 区分。待验证材料也可启发新路线。问题包引用现有锚点和必要证明，不重复生成全套背景。

按 literature.md 在新方向、较大证明投入和新颖性判断时核对已有成果。检索也可帮助修补具体步骤、寻找构造变体、跨领域类比或替代路线。采用线索时说明起作用的机制、所需条件以及接入当前问题的关键位置；不只罗列相似标题，也不把检索固定为探索前的独立阶段。

### 按需使用计算与数据

选择计算或数据辅助探索时，把观察到的规律表述成对象、量词和参数范围明确的候选命题。按问题选择精确实例、极端或退化情形、参数变化及与已有结果的比较，寻找能区分解释或改变路线判断的证据；有条件时检查不同来源或生成方式的数据。把计算线索与机制、构造及证明所需条件联系起来。样本相关和预测准确率支持猜想，不代替一般证明。

只有预期能澄清当前数学问题时才运行计算实验，说明检验对象、输入范围和结果的意义。涉及浮点、采样或优化时保留精度、误差与搜索范围；反例候选须核对对象合法性及违反条件，必要时用精确计算或误差界确认。有限穷举只有在覆盖范围及计算正确性足以支持结论时，才能承担对应有限命题的证明。保存影响结论的代码、数据和参数，平常的小计算无需新增实验框架。

## 适度复查与独立核验

新论证、核验反馈及依赖变化统一按 mathematical-judgment.md 处理，包括检查范围、完整送审材料、首轮独立判断、分歧处置和后续定向复核。研究角色只决定职责与协作，不另设数学裁决层级。

探索者或证明者可提出核验需求，在主代理安排后直接交接实际材料，无需主代理转述证明。按问题区分候选结果、文献适用性和整合论证，可以合并相关检查或按独立问题拆分。核验者直接向主代理返回有理由的发现，并向承担修订的作者提供所需反馈。

验收未通过或批评成立且需要修订时，给出准确位置、数学理由和通过尺度，优先交原执行者修改原产物。主代理判断修补的研究价值；没有新信息时不机械重复同一返修循环，回到实际争点、适用假设和路线取舍。确有执行障碍时再调整安排或接手。

## 整合与人类协作

主代理决定可接纳的论证及整合安排，核对实际文本和连接，保留未决依赖及有价值的失败。上下文恢复、核验记录与证据保存按 research-workbench.md 处理；当前研究安排只在下一次入口维护，日志追加重要处置与改道理由。

能自行解决的方法选择继续推进。目标或结论强度需要人类取舍、关键输入确实缺失，或合理尝试后仍不能继续时，说明已知事实、具体障碍、推荐方案与替代选项，然后停在可恢复位置等用户回答。用户只要求一轮时完成该轮；局部结束、保存成功、阶段目标完成和用户暂停分别报告。
