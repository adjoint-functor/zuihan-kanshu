# 全项目共享中文参考

中文模组实际适用时，解析并读取这份个人持久参考，使用已查证补充及用户明确的翻译习惯、用词偏好和保留词规则；研究内部与报告阶段的适用边界仍按 `SKILL.md`。它服务所有项目，规则各依实际授权范围生效，与每篇文章的“术语与翻译表”职责独立。

## 位置与读取

默认位置是**云端 Library 根目录中的 `瑞般观珠/zuihan-kanshu-Chinese.md`**，与 `瑞般观珠/` 下各项目子目录并列。它不是项目控制文件、操作系统 `/root`、插件缓存或公开仓库文件。用户明确指定共享文件或其位置时遵从；普通稿件保存目录指令不迁移此文件，局部任务也不另造一份共享副本。

默认云端位置按当前宿主的 Library 技能真实搜索、定位目录与文件身份并读取；用户明确指定本地共享路径时使用实际文件工具，不到 Library 中查找本地路径。同一轮已读且仍适用可复用；更新前须读取最新版本。有同名歧义时核实目录身份，不靠名称猜选或创建额外副本。确证所选目录或文件不存在时，创建所缺目录及最小空模板，无需为默认初始化反复询问：

```markdown
# 瑞般观珠共享中文参考

## 已查证补充译名

暂无条目。

## 用户明确的个性化与例外规则

暂无条目。
```

读写失败或缺少工具不等于文件不存在。保留可恢复的候选与尚缺操作，简短说明实际状态，不假报云端已保存；按已取得的有效规则继续可行工作，不把未读到的偏好说成已经确认。

## 只维护两类已落实内容

- **补充译名**：只收录内置表未覆盖、已按 `chinese-translation.md` 查证落实的条目。记录原词及语言、数学义项或对象限定、采用的中文或有依据的保留形式、可靠来源 URL 与定位、核实日期和适用范围。候选、未决词和机器猜译不入表，不凭拼写跨义复用。
- **用户明确规则**：包括明确采用的个性化翻译习惯、用词偏好和保留词要求。记录对象或词类、采用形式／保留不译／其他要求，适用范围（本次、本稿、项目或全局），明确指示的简要依据和日期。“此处译为”“以后保持英文”等语义明确即可，不需固定口令；随口用词、临时简称、提问用语、助手自建术语表和重复用法都不构成授权。局部批准不得升级成全局规则。

已有用户内容须保留；历史或限定范围的规则只在仍适用时采用。共享文件中的规则不授权改变数学内容，也不改写受保护的引文和书目字段。

## 优先级与复用

译名优先级统一按 `chinese-translation.md`：当前明确要求、仍适用的明确用户规则、任务适用的源文双语约定、内置精确表项、共享已查证补充、必要的新查证。共享补充是已查证缓存，只在义项及证据适用且无冲突时复用，不能覆盖内置精确表项；明确的用户例外按其授权范围优先。新冲突或义项变化重新查证，不静默扩张旧条目。

## 增量保存

无合格增量时不重写文件。保存前读取最新内容，合并本次已落实条目，核对义项、作用域和重复；每个共享写入区域只设一个负责人。沿既有文件身份保存，并使用宿主支持的当前版本校验；发生冲突后重读合并，不覆盖并发修改，不全量重造用户内容。实际保存成功后才报告已更新；失败保留候选以便补做。

共享参考的读取、必要初始化和合格增量，是普通对话不新建稿件／控制／研究文件的独立例外。它不削减或替代文章末尾适用的术语表，不把共享全表复制到文章中，也不自动修改内置表。
