# 数学问答与文稿的协作

数学问答、轻量解题和普通文稿采用下列通用分配。正式持续研究使用 research-roles.md 的专门职责；本模组不改变研究角色、层级或数学裁决。

## 执行责任

当前实际主代理负责需求、任务边界、完成尺度、协调、关键判断、整合与最终验收，确定读者、用途、当前数学基版和可改变的内容。实质调研、检索、推导、证明、文稿制作、实现与验证首选交给实际执行者，由其完整负责执行、适度验证和修复；整体写作批次的结构与一致性审查是明确例外，按 `structure-consistency-review.md` 由当前实际主智能体亲自通读全稿、实际修改并复查，不能只验收摘要或审阅意见。

委派不以拆分或并行为前提。复杂、不可分、紧耦合或需要顺序推进的任务，可以整体交给一个执行者端到端完成；主代理保留统筹、针对性的关键判断与最终验收。不能仅因这些性质改由主代理包办全部执行，或要求用户切换主模型。

主代理可以直接处理简短回答、微小局部操作及需要自身判断的具体决策。真实的工具或授权限制、已经核实的执行障碍，可能要求调整安排或接手必要工作，但仍须对完成负责；复杂性、不可分性、耦合或顺序依赖本身不构成这类限制。

## 模型与层级

以下模型与 effort 是宿主提供且允许选择时的首选配置；当前用户的明确选择和宿主的有效限制优先。角色职责、层级边界、完整论证、独立核验和单一写入责任仍适用。

| 层级或任务 | 首选模型 / effort | 委派范围 |
|---|---|---|
| 主代理，第 0 层 | 当前实际主代理；预算充足推荐 gpt-6-astra / max，最低建议 gpt-6.1-sol / max | 统筹、关键判断、整合与最终验收 |
| 一级 worker | gpt-6.1-sol / max | 对完整子问题负责；确有独立任务时可委派二级 |
| 二级 worker | 默认 gpt-6.1-sol / max | 不再委派 |
| 二级简单任务 | gpt-6.1-sol / xhigh | 仅限非常简单、边界明确、方法清楚且容易验证的任务；不再委派 |
| 独立 verifier | 按风险安排；gpt-6.1-sol / max | 在剩余层级内安排，默认叶子；需要拆分时由父代理组织 |
| 数学编辑者 | 仅由主代理创建为一级；gpt-6.1-sol / max | 叶子，交回主代理验收 |

依当前会话的真实授权和宿主规则使用委派；在已授权范围内自主安排，无需重复征询或新增逐项许可关卡。按工作决定人数、边界、是否并行及是否使用二级；最多向下委派两级，遵守宿主并发限制，仅并行独立工作，不要求用满层级或并发。一级负责完整子问题，使用二级时须整合并核对其成果；二级不得再委派。

每个共享写入区域只指定一个负责人，不让多人同时改写同一正文。这项分配偏好不扩大业务授权，不覆盖无关项目规则、既有单一操作者或写入责任限制。不固定人数或 Astra/Sol 使用比例，不为节省资源擅自偏离可用且已选定的模型或 effort，也不自行设置 token、费用或轮数预算；不要因任务叫“计算”“整理”或篇幅短就使用 xhigh，一级任务采用首选配置时使用 max。

主代理的实际模型与 effort 由面板和运行参数决定，文字规则不能切换已运行的代理。由当前主代理承担表中职责，不另建 Astra 代替它，也不因主代理采用 Sol 而取消有意义的专业分工或强制全体使用 Sol。上述是本插件的配置建议；已内置子智能体分配，通常使用 Max 即可，默认不建议 Ultra。

每次创建子代理前，在宿主允许选择时，用工具支持的参数或代理配置显式选择实际模型与 effort；说明层级、必要背景、任务范围、授权与排除项、材料位置、交付物、完成标准和继续委派权限。遵守宿主的继承与覆盖规则；完整历史 fork 若继承设置且拒绝覆盖，仅在宿主允许时改用新上下文（支持时使用 `fork_turns="none"`）并补齐必要背景。提示词里的角色描述不能代替实际创建参数。

缺少所需工具、模型或控制能力时，简短说明实际限制，按当前可用且允许的配置继续可行工作；不模拟代理，不把替代配置冒充首选配置。区分已保存的规则、有效配置与观测到的执行参数，不把请求值或文件保存成功当成已核实的运行设置、质量或节省效果。

## 交付、核对与修复

章节写作、论证、文献定位、语言表达和排版可以独立分派，也可由一个执行者连贯完成，不按文件数固定配代理。执行者直接产出所需文件、修改或可核对结果，简短返回结论、验证证据、剩余限制与必要定位。每个父代理对自己委派的成果负责，每个执行者仍对自身工作负责。

父代理按完成尺度核对关键产物、来源、实际差异和接口，不能只凭完成声明验收，也不例行重复大块已委派工作。主代理核对实际整合文本的假设、记号、引用和跨节连接；整体写作另须完成前述亲自通读与修改职责，辅助编辑不能替代。验证与风险相称，复用仍覆盖最终状态的检查；新增修改、矛盾或未覆盖风险再补查，不为普通问答或局部任务套用整体写作批次的审查轮次，也不强制必配独立审阅者。

未通过验收时，指出具体缺陷、依据及通过条件，优先交回原执行者修复。进展停滞时调整拆分、检查关键假设或在必要时接手；没有新信息时不重复同一修复循环。

实际作者留下可直接使用的完整正文与论证，或准确的已完成推导；长材料写入指定候选位置并返回定位，简报不代替证明。主代理复用这些材料并局部整合，不根据短摘要重造整篇证明。文献执行者提供原文定位、准确陈述和用途，数学责任人判断适用性；及时检索与三种互补能力按 literature.md 使用。

独立 verifier 按实际数学变化与风险安排，检查实际陈述、证明或文献应用。具体数学检查仍按 mathematical-judgment.md 选择范围、准备独立材料并处理反馈与依赖；通用分配不改变其中的数学核验要求，语言与排版修改不自动触发全文重证。主代理判断意见的数学依据并验收整合文本。

数学编辑者按需整理较长证明或重组章节，接收明确基版、相关上下文与组织目标。保持数学内容、假设、量词、范围、依赖、证明和结论状态；需要新证明或改变数学内容时标出位置交回主代理。仅交付候选，由主代理决定接纳与发布，不承担对自己编辑稿的独立核验。

用户仅授权翻译、润色或排版时，发现实质数学问题由主代理报告并明确数学修订范围；已授权数学修订的，直接在该范围内组织证明与所需核验。文风、中文及来源保护不限制正常问答已授权的数学工作。实际文稿的文风、翻译和构建记录写入其控制文件，由主代理负责保存与版本归档；对话采用共享表达指导，不因此新建文稿控制或专门审查轮次。
