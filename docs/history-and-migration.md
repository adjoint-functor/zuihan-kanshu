# 版本与迁移

## 公开边界

v8.3.0 是本仓库整理后的公开源码起点。此前完整提交历史与私人维护记录保留在原私有库，不随新仓库公开；这里保留理解当前设计所需的通用沿革和可复现材料，不复制内部协作流水或私人研究材料。以下阶段说明不表示此前存在公开发布。

| 阶段 | 留在当前设计中的内容 |
| --- | --- |
| v7 | 中文数学写作、来源记录、协作与核验、成品制作的基本约定 |
| v8 | 数学问答、持续研究和普通文稿三条路径；研究五文件；论证状态与文献适用性；中文与文风模组；PDF 编译预检 |
| v8.1–v8.2 | PDF 环境与字体检测、可移植插件构建、产品入口和图标资源 |
| v8.3.0 | 统一技术标识、明确宿主能力边界，整理公开源码、文档与可复现示例 |
| v8.3.1 | 补充双语致谢与安装说明，完善全部平台可用地区及无购买的发布元数据；运行时行为不变 |

## 名称与目录

早期技能标识为 `author-chinese-math-docs`；v8.3.0 统一为 `zuihan-kanshu`，中文显示名为“瑞般观珠”。运行时源码位于 `skill/zuihan-kanshu/`，插件中的技能位于 `skills/zuihan-kanshu/`。

升级既有安装时，使用目标宿主提供的移除、替换或导入方式，检查是否残留重复技能；不要假设仓库改名会自动更新宿主安装。已有研究文件与文稿的主题名不必随技能标识改变。

## 既有工作如何继续

1. 保留原项目文件与已验证证据，从当前入口确认目标、可靠成果、未决依赖和保存位置。
2. 研究项目检查同版本五文件与 `download/`、`tmp/`、`old/`；已有额外代码、数据与证书继续保留，不为套用模板删除研究材料。
3. 普通文稿沿用既有来源与当前版本，按本次实际修改范围补充控制信息；迁移标识本身不要求重写全文或重建全部 PDF。
4. 在实际宿主中确认可用的模型、委派、检索、文件和编译能力。本地初始化或归档操作完成后，远端保存仍须通过对应能力实际执行并确认。

运行时协议见[研究工作台](../skill/zuihan-kanshu/references/research-workbench.md)和[普通文稿](../skill/zuihan-kanshu/references/working-draft.md)；完整变化摘要见 [CHANGELOG](../CHANGELOG.md)。
